# Reorganização de contexto

Responsável por estudar como uma conversa longa pode ser reorganizada antes de ser enviada novamente ao modelo.

Objetivos futuros:

- separar contexto ativo de histórico antigo;
- preservar decisões, objetivos, restrições e pendências;
- compactar conteúdo repetitivo;
- recuperar informações antigas apenas quando necessário;
- reduzir consumo de tokens sem apagar informação importante.

A implementação inteligente será feita em etapas posteriores.
